# 通信与数据链路

## 已确认链路

1. 肌电模拟前端输出接入 ADS131M08 八通道 ADC 工程所示输入连接器。
2. ADC 数字数据由 ESP32 主控读取；原理图网络/总线参数尚未从可读设计中核实。
3. ESP32 主控与独立 ESP8266EX Wi-Fi 板通过 UART 连接（基于项目描述）。
4. Wi-Fi 模块通过 UDP 发送数据（基于项目描述）。

```text
电极 → INA333 / OPA333 → ADS131M08 → ESP32-S3(R8)
                                      ⇅ UART
                                  ESP8266EX → UDP → 接收端
```
