# 硬件说明

## 系统组成

| 模块 | 工程中确认的器件 | 备注 |
|---|---|---|
| 肌电模拟前端 | INA333（U1）、OPA333（U5/U6）、三枚电极符号；R/C 元件 | 来自 `esp32_demo` 与 `ProDoc_PCB2` 工程，尚未确认与八通道系统的最终接线/复用关系 |
| 八通道 ADC | ADS131M08、8.192 MHz 时钟元件、H1–H8 八组 4 针连接器及一组 8 针连接器 | ADC 工程 `ADC_2026-10-24`；参考时钟标号 OSC1。未核实配置、通道顺序及连接器定义 |
| 主控早期版本 | ESP32-C3FH4、BQ25185 充电管理、TPS63031 电源器件 | 工程日期 2026-10-25，非最新主控版本 |
| 主控后续版本 | ESP32-S3(R8)、XT25F16 外部 Flash、BQ25185、TPS63031 | 工程日期 2026-10-29；用户描述主板带外部 Flash |
| 当前最新主控 PCB | 用户提供的 2026-11-13 EDA Pro 工程与 PCB 布局截图 | 最新文件已归档；元件清单和原理图细节仍需在 EDA Pro 中复核 |
| Wi-Fi 模块 | ESP8266EX、W25Q80 外部 Flash、板载天线符号 | 工程日期 2026-10-25；用户描述 UART 接主控、UDP 发送 |
| 滤波器工程 | 独立 `filter` 原理图工程 | 工程内器件实例尚未完整映射到准确型号与阻容值，暂不描述截止频率/拓扑 |

## 版本注意

按日期，主控工程依次为 2026-10-25、2026-10-29、2026-11-01 和 2026-11-13。用户明确确认 2026-11-13 文件是最新版本，并提供对应 PCB 布局截图。2026-10-25 工程是 ESP32-C3FH4，2026-10-29 工程改为 ESP32-S3(R8)。不要把不同日期版本的元件清单合并成同一块板；11-13 版本的器件与网络资料待 EDA 页面复核。

## 仍待核实的设计细节

- 各模拟前端 R/C 的标称值、增益、滤波截止频率、保护网络和供电电压。
- ADS131M08 的 SPI 引脚、时钟/采样设置、参考源与各连接器的通道对应关系。
- ESP32-S3 与 ADC 的具体网络连接、Wi-Fi UART 引脚及波特率。
- PCB 层数、板框尺寸、制造参数和各工程是否已打样验证。

## 原始工程

可在 `hardware/main_controller/`、`hardware/emg_sensor/`、`hardware/wifi_module/` 中找到作者提供的 EDA Pro 工程归档。它们是多个时间点的工程版本；打开后请核对项目日期和保存状态。器件型号按原理图 `COMPONENT` 实例识别，封装库中的候选器件不作为实际 BOM 依据。
